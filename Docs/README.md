# Docs Map

RegProbe's docs now split along the same boundary as the product story itself:

- [Product docs](product/README.md)
  - what the app does
  - how to use it safely
  - what the public visuals are trying to teach
- [Research docs](research/README.md)
  - how to read records
  - how the proof model works
  - how VM, runtime, and script lanes support the evidence contract

If you are here for first use or evaluation, start in `Docs/product/`.

If you are here to validate claims, extend the pipeline, or maintain the evidence system, start in `Docs/research/`.
